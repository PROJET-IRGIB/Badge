# Badge
Application permettant de concevoir des badge pour des étudiants D'IRGIB AFRICA

La maquette est dans le dossier `irgib-campus/`, pas dans une archive.

- `irgib-campus/etudiant/` : espace étudiant
- `irgib-campus/admin/` : administration
- `irgib-campus/assets/` : catalogue, styles et blason partagés

Sur Windows, lancer `irgib-campus/start-demo.ps1`. L'étudiant s'ouvre sur http://localhost:8765/etudiant/ et l'administration sur http://localhost:8765/admin/.
